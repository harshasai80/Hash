Events API

Browse campus events and manage event registrations with these endpoints.

MethodEndpointDescription
GET/api/eventsBrowse events.
GET/api/events/{id}Event details.
POST/api/registrationsCreate registration, 201 or 409.
GET/api/me/registrationsCurrent user’s registrations.
GET/api/events/{id}/registrationsAttendee list, owning organizer only.
